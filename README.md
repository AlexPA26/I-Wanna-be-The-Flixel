# 🕹️ I Wanna Be The Flixel
### An "I Wanna Be The Guy" fangame created with [HaxeFlixel](https://haxeflixel.com)

Created from the ground up, this is an individual project of recreating a difficult and fun to play platformer. Heavily inspired by [I Wanna kill the guy](https://delicious-fruit.com/game/12373) by Thenewgeezer

---

## ⚠️ How it plays

It's a solo adventure of (currently) about 50 screens in total. For every couple screens there is a new gimmick or idea added to the mix.

Currently the game has only a few areas, each with unique atmosphere and ideas:

1. **Castle Outdoors:** Acts as the tutorial for the game. Basic platforming.
2. **Castle Inside:** This is where the game REALLY starts.
3. **Sewers:** Underground area filled with toxic liquids, tight platforming and new gimmicks-
4. **Castle Daytime:** Acts as a segue and a place to relax.
5. **The Circus:** Small area acting as a pre-intro to the main Chapter boss

---

## 🎮 Controls

* **Move:** Left / Right Arrow Keys or A / D
* **Jump:** Up Arrow, W, Spacebar or Left click
* **Pause Menu:** Escape
* **Fullscreen:** F11

## 🛠️ Building & Compiling

This game is built on the HaxeFlixel engine. To compile it from source:

1. Install [Haxe](https://haxe.org/download/) and [Haxelib](https://lib.haxe.org/).
2. Install HaxeFlixel: `haxelib install flixel`
3. Install required dependencies:
   * `haxelib install openfl`
   * `haxelib install lime`
   * `haxelib install flixel-addons`
   * `haxelib install flixel-ui`
4. Run the build command for your target platform (e.g., Windows):
   ```bash
   lime test windows -debug
   ```
